# ADR-0012: electron-builder NSIS installer, per-user, no admin

- Status: Accepted, 2026-11-05

## Decision
- electron-builder `nsis` target: `oneClick: true`, `perMachine: false`, `allowElevation: false`. It installs to `%LOCALAPPDATA%\Programs\AgentDeck`, with Start menu and desktop shortcuts.
- `appId` / AppUserModelID is `com.thirdcode.agentdeck`. It is set in main via `app.setAppUserModelId` so toasts work (R19).
- **Autostart:** `app.setLoginItemSettings({openAtLogin: true})` on the first run, toggled from Settings. "Start minimized" is off by default and passes `--hidden`.
- **Uninstaller:** a `customUnInstall` NSIS macro runs `"$INSTDIR\AgentDeck.exe" --uninstall-integration` and waits up to 10 s. That command removes only our hook and OTel entries (ADR-0005, ADR-0007) and exits without opening a window. App data stays unless you tick "Delete AgentDeck data".
- No code-signing certificate in v1. SmartScreen will warn, and the README says so. Auto-update is off (ADR-0009).
- CI on `windows-latest`:
  1. `npm ci`
  2. typecheck, lint, Vitest
  3. `electron-builder --dir`
  4. Playwright-Electron smoke test against the unpacked build

## Consequences
- No admin rights at any point.
- Uninstalling leaves `settings.json` exactly as it would be without AgentDeck.

## Amendment: macOS, 2026-11-15
- electron-builder `mac` target: `dmg` and `zip`, each for `arm64` and `x64`, category `public.app-category.developer-tools`, icon `build/icon-mac.png` (1024 px, generated by `scripts/make-icons.ps1`). `npm run dist:mac` builds them on a Mac; `npm run dist` stays the Windows installer.
- **Not notarized, no Developer ID**, like the unsigned Windows installer: `hardenedRuntime: false` and `identity: '-'`, an ad-hoc signature. Without any signature a downloaded Apple-silicon build is reported as "damaged" with no way past it; with an ad-hoc one Gatekeeper offers Open (Control-click > Open, or Privacy & Security > Open Anyway). The README says so and gives `xattr -dr com.apple.quarantine`.
- The Dock icon stays (no `LSUIElement`): it carries the badge count (`app.dock.setBadge`) and clicking it reopens the window (`app.on('activate')`). Closing the window still keeps AgentDeck running in the menu bar, as on Windows. The plain menu bar icon is a template image; the coloured status icons keep their colour so red, amber and gray still read.
- `setAppUserModelId` runs on Windows only. The packaged app sets the standard macOS menu (App, File, Edit, View, Window roles) so Cmd-Q, Cmd-C/V and Cmd-W work; Windows keeps no menu.
- **Autostart:** the same Settings switch. macOS ignores login-item `args`, so "start minimized" uses `wasOpenedAtLogin` with the stored setting instead of `--hidden`.
- `Info.plist` carries `NSAppleEventsUsageDescription`: Attach and Terminal here drive Terminal or iTerm with `osascript`, and macOS asks once for Automation consent.
- **Uninstall:** there is no uninstaller to run `--uninstall-integration`. Quitting removes the hook entries (ADR-0005); after a crash the README gives the command to run by hand before deleting the app.
- CI adds a `macos-latest` job: `npm ci`, typecheck, lint, Vitest, `electron-builder --dir`. The Playwright smoke tests stay on Windows until they are proven on a macOS runner. The release workflow builds the dmg and zip on `macos-latest` after the Windows job has drafted the release, uploads them to that draft and appends their lines to `SHA256SUMS.txt`.

# Getting help

AgentDeck is free software maintained by one person in spare time. Here is where to go, fastest first.

- **Something is broken.** Open a [bug report](https://github.com/kurtgav/Agent-Desk/issues/new?template=bug_report.yml). Include the output of **Settings, Diagnostics, Copy diagnostics**: it answers most of the questions I would otherwise ask.
- **A question, or "how do I...".** Use [Discussions](https://github.com/kurtgav/Agent-Desk/discussions). Please read the [README](README.md#faq) and the docs first: [Architecture](docs/ARCHITECTURE.md), [Compatibility](docs/COMPATIBILITY.md) and [Risks](docs/RISKS.md) list what is known and what is not verified.
- **An idea.** A [feature request](https://github.com/kurtgav/Agent-Desk/issues/new?template=feature_request.yml) is fine. Keep in mind AgentDeck will not add network access, model calls or automatic approvals.
- **A security problem.** Do not post it publicly. Follow [SECURITY.md](SECURITY.md).
- **Want to fix it yourself.** [CONTRIBUTING.md](CONTRIBUTING.md) has the setup and the rules.

## What is and is not supported

- Windows 11 and the latest release only.
- Claude Code as tested in [COMPATIBILITY.md](docs/COMPATIBILITY.md). Claude Code changes often, so a newer version may behave differently than the table says. Say which version you run.
- There is no paid support and no response time promise.
